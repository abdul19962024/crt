# بوت إشارات الذهب M30 — تيليجرام

هذه الحزمة تستبدل استراتيجية H1/M2 القديمة باستراتيجية **XAUUSD فقط**:

- التاريخ وتكوين مناطق M30 من مكتبة Python القديمة `tvdatafeed` على `FX_IDC:XAUUSD`.
- السعر الحالي، لمس المنطقة، متابعة الوقف والتقدم من تدفق السعر الحي `watchQuotes` في `@mathieuc/tradingview`.
- لا يوجد مسار ناسداك، ولا إرسال أوامر إلى وسيط.

## قواعد الاستراتيجية المنفّذة

1. تُستخدم شمعتان M30 متجاورتان مكتملتان. يجب ألا يتجاوز الفرق بين إغلاق الأولى وافتتاح الثانية **0.10$**.
2. شمعتان خضراوان: منطقة شراء. شمعتان حمراوان: منطقة بيع.
3. شمعتان متعاكستان: الأخضر ثم الأحمر للبيع، والأحمر ثم الأخضر للشراء.
4. عند أول لمس حي للمنطقة تُرسل التوصية فورًا. الدخول المسجل هو Ask للشراء وBid للبيع عند وصول تحديث اللمس.
5. وقف المتابعة ثابت **4.00$** من سعر الدخول، والهدف مفتوح. تُرسل متابعة عند +3$ ثم كل +2$ إضافية. عند بلوغ الوقف تُرسل رسالة متابعة.
6. لا تُرسل إشارات قديمة عند تشغيل الخدمة: المناطق التي يظهر في التاريخ أنها لُمست قبل اكتشافها تُعلّم مستهلكة. الصفقة لا تُكرر للمنطقة نفسها.
7. تُحصر المناطق الجديدة في يوم الرياض الحالي وتنتهي عند منتصف الليل؛ الصفقات المفتوحة تظل تحت المتابعة حتى الوقف.

## التثبيت والتشغيل

يتطلب تشغيل الجسر Node.js 20 أو أحدث، إضافة إلى Python 3.10 أو أحدث:

```bash
pip install -r requirements.txt
npm install --omit=dev
python snb_gold_m30_live_telegram.py
```

على Render، استخدم مثلًا:

- **Build command:** `pip install -r requirements.txt && npm install --omit=dev`
- **Start command:** `python snb_gold_m30_live_telegram.py`

يجب أن تكون ملفات Python و`package.json` و`node_modules` والجسر `snb_tv_quote_bridge.mjs` في مجلد الخدمة نفسه. إذا كانت خدمة Render الحالية لا يتوفر فيها `node`، يلزم إضافة Node.js 20+ إلى بيئة التشغيل (أو استخدام Docker)؛ لا يستطيع ملف Python تشغيل مكتبة JavaScript من دون Node.

## متغيرات البيئة

أبقِ بيانات تيليجرام في إعدادات الخدمة، لا داخل الملفات:

- `TELEGRAM_API_ID`
- `TELEGRAM_API_HASH`
- `TELEGRAM_SESSION_STRING`
- `TELEGRAM_CHANNEL`

اختيارية: `TELEGRAM_ENABLED`, `TIMEZONE` (الافتراضي `Asia/Riyadh`), `SNB_DATA_DIR`, `HISTORY_BARS` (300), `HISTORY_REFRESH_SECONDS` (30), `QUOTE_STALE_SECONDS` (30), `EQUAL_TOLERANCE` (0.10), `FIXED_STOP_DOLLARS` (4.0).

رسالة البدء «اللهم صلِّ...» تبقى كما سبق وتُرسل عند كل تشغيل. عند وجود حالة قديمة، يستمر تتبع الصفقات النشطة من النسخة السابقة للوقف والتقدم فقط؛ لا تُولّد إشارات أو إعادات H1/M2 جديدة.

## مصادر وحدود البيانات

تم اختبار جلب شموع M30 من `tvdatafeed` ومراقبة `FX_IDC:XAUUSD` عبر `watchQuotes`. المكتبتان غير رسميتين وتعتمدان على توفر تغذية TradingView دون تسجيل دخول؛ قد تكون التغذية محدودة أو مستبدلة أو تختلف عن وسيطك. يُوقف البوت فحوص اللمس والوقف عندما لا يصل تحديث حي حديث بدل الاعتماد على سعر محفوظ.
